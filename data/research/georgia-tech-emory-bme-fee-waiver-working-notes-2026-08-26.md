# Georgia Tech–Emory Biomedical Engineering Fee-Waiver Working Notes — August 26, 2026

## Official sources reviewed

1. Georgia Tech Graduate Education — Application Fee Waivers: https://grad.gatech.edu/admissions/application-fee-waivers
2. Georgia Tech Graduate Education — International Applicants, Step 6: https://grad.gatech.edu/admissions/international/ready-to-apply
3. Coulter BME — Apply Now: https://bme.gatech.edu/apply-now
4. Georgia Tech Bioengineering FAQ: https://bioengineering.gatech.edu/faqs

## Verified findings

Georgia Tech Graduate Education currently provides institute-level application-fee waivers for participants in specific programs and directs applicants to request the waiver within the online graduate application with required documentation. Only one institute-level waiver may be approved per admission cycle. The request must be submitted before the program deadline; applicants should not pay before a decision because the fee is non-refundable. Georgia Tech says waiver decisions are communicated by email within 5–10 business days. If an applicant does not qualify for an institute-level waiver, the applicant should contact the graduate program because department-level options may exist. The international-applicant page states that international applicants must submit required application materials before requesting a waiver and that Georgia Tech does not review international financial-hardship requests for institute-level waivers.

The Georgia Tech Bioengineering FAQ says waiver requests should be submitted to the home school and that some home schools participate while others do not. The BME/Emory Apply Now page confirms the joint Biomedical Engineering Ph.D. program and Georgia Tech master’s pathways. The joint Ph.D. uses a Georgia Tech home-school application; the master’s page describes multiple home-school/program pathways. Therefore, a general Georgia Tech application-fee waiver request route can be shown separately on the published joint BME Ph.D. and M.S. profiles, but no automatic approval, code, named category, or Emory-specific route is inferred.

## Safe application wording

Use `fee_waiver_form` entries pointing to the official Georgia Tech Application Fee Waivers page. State that eligible applicants request the waiver inside the online graduate application with documentation, must submit before the program deadline, should not pay before a decision, and should contact the applicable home school for department-level options. Preserve the 5–10 business-day decision estimate and the one-waiver-per-cycle rule. Do not claim that all BME applicants qualify; do not extend international financial-hardship eligibility beyond the official limitation.

## Boundary

Apply the route independently to the published Georgia Tech–Emory BME Ph.D. and M.S. records because the central Georgia Tech procedure covers graduate applicants but home-school eligibility can differ. Do not create a blanket Emory fee-waiver claim or transfer a BME route to unrelated programs.
