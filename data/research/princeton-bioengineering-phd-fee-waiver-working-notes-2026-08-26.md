## Verified findings

Princeton’s current Graduate School fee page states that a nonrefundable US$90 application fee is required and that applicants may request a waiver for financial hardship, participation in a listed qualifying program, recruiting-event attendance using the event code received, or virtual-workshop attendance. The listed programs include McNair, IIE/Fulbright, Leadership Alliance, NSF-REU, U.S. Military, and other named programs. Requests are completed in the graduate application’s Fee Waiver Request page. Princeton encourages early submission; the waiver-request deadline is two business days before the department application deadline. Decisions are emailed within 2–3 business days. If denied, the applicant must submit the application and pay by the deadline; applicants should not pay before receiving a decision because fees are nonrefundable.

Princeton Engineering’s FAQ confirms that eligible recruiting events and qualifying programs are selected in the application and that financial-hardship requests require supporting documentation. The current Bioengineering page confirms the published program is the Bioengineering Ph.D.; Fall 2027 applications open in September 2026. No separate Bioengineering code or form is published on the department page.

## Safe application wording

Add a `fee_waiver_form` route to the published Princeton Bioengineering Ph.D. profile pointing to the official Graduate School application-fee page. State the current US$90 fee, qualifying waiver categories, in-application request process, two-business-day-before-department-deadline timing, 2–3-business-day decision window, documentation requirement for financial hardship, and non-refundable/no-pay-before-decision boundary. For recruiting events, state that the application accepts only listed events and requires the code received from the event. Do not claim universal eligibility or invent a Bioengineering-specific code.

## Boundary

The published record is a Princeton Bioengineering Ph.D. profile. The incidental M.A. described on the department page is not a separate application profile and should not receive an independent route. Do not transfer this guidance to unrelated Princeton master’s programs.
