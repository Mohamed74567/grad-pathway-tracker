# Complete Source-Material Archive

This directory preserves the complete source-material collection available during the GradPathway Tracker build. The `upload-archive/` directory contains the original uploaded HTML source and all captured research materials, including official-source page extracts and downloaded image assets.

The archive contains **1,459 files** totaling approximately **447.9 MB**. The largest individual file is approximately **3.96 MB**, so no archive file exceeds GitHub’s standard single-file limit. No environment files, private keys, certificate files, or similarly named secret files were found in the archive during export.

The application’s canonical structured records remain under `data/`, while this directory is a provenance and backup archive. The running application continues to use the verified structured data and managed-storage image URLs. The image copies under `assets/university-images/` provide a separate repository-local backup of all available university images.

The original uploaded project source is preserved at:

`data/source-material/upload-archive/PHDUniTracker.html`

Research notes and official-source logs remain available under `data/research/`.
