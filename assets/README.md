# GradPathway Tracker Assets

This directory contains the image assets available for the GradPathway Tracker export. The university images are kept in `university-images/` so the private GitHub repository includes local copies for backup, inspection, and future development.

The running application continues to use its verified `/manus-storage/...` image URLs. Those managed-storage references are intentionally preserved because they are the URLs used by the deployed application. The local copies in this directory are repository-side assets and are not a replacement for the deployed storage URLs unless the application is later migrated to serve them directly.

The export includes all available image files copied from the project’s managed asset workspace, along with the complete `data/` directory containing program records, audit data, official-source logs, state queues, and research notes. No environment files, private keys, or generated build directories are included.

Image provenance and university-specific source notes remain documented in `data/research/official-source-log.md` and the state-specific research files.

## Inventory

The current export contains **141 image assets** in `university-images/` and **177 data files** under `data/`. The asset filenames are intentionally descriptive and retain their original file extensions.
